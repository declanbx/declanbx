### Claude Code tools
- **[keepwarm](https://github.com/declanbx/keepwarm)**: keeps an idle session's prompt cache warm
- **[newsession](https://github.com/declanbx/newsession)**: opens a new Claude Code session in its own Terminal window (macOS)
- **[inkscape-live-mcp](https://github.com/declanbx/inkscape-live-mcp)**: MCP server that drives a live Inkscape window (macOS)

### Utilities
- **[lens](https://github.com/declanbx/lens)**: fast searchable indexer for large folders (macOS)

### Lab tools
- **[LabCalc](https://github.com/declanbx/LabCalc)**: dilution and molarity calculators
- **[LabCalendar](https://github.com/declanbx/LabCalendar)**: feeding tracker
